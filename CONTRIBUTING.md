# Contributing to Stellar Axis

First off, thank you for considering contributing to Stellar Axis! It's people like you that make the Stellar ecosystem a better place for everyone.

## 🧭 Project Ethos
Stellar Axis is an open-source infrastructure protocol. We value:
- **Security**: Our contracts protect user assets.
- **Simplicity**: Developers should be able to integrate in minutes.
- **Performance**: High-throughput indexing and relaying.

---

## 🛠 How to Contribute

### 1. Find an Issue
Look for issues labeled `tier-1`, `tier-2`, or `tier-3` depending on your experience level:
- **Tier 1 (Stargazer)**: Perfect for your first contribution. Usually docs, minor UI fixes, or tests.
- **Tier 2 (Builder)**: Requires knowledge of TypeScript/Next.js or basic Rust.
- **Tier 3 (Architect)**: Deep dives into Soroban contracts or ZK proofs.

### 2. The Workflow
1. Fork the repository.
2. Create a feature branch (`git checkout -b feat/your-feature`).
3. Make your changes and ensure all tests pass.
4. Submit a Pull Request.
5. Participate in the code review.

---

## 🎖 Contributor Progression System

We recognize and reward our contributors:
- **Stargazer**: 1st merged PR. Recognition in our README.
- **Builder**: 3+ meaningful PRs. Access to our private "Builders" channel.
- **Architect**: Authored a major feature or module.
- **Axis Guardian**: Vetted maintainer with write access to specific modules.
