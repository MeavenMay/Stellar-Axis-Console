# 🪐 Stellar Axis Console

### The Premium Management Dashboard for the Axis Ecosystem.

[![Stellar](https://img.shields.io/badge/Stellar-Soroban-black?logo=stellar&logoColor=white)](https://stellar.org)
[![Framework](https://img.shields.io/badge/Next.js-14-black?logo=next.js)](https://nextjs.org)

**Axis Console** is the official developer dashboard for the [Stellar Axis](https://github.com/MeavenMay/stellar-axis-core) ecosystem. It provides a high-fidelity interface for developers to manage their paymaster balances, monitor smart account activity, and configure relaying policies.

---

## 🚀 Features

- **Developer Overview**: Real-time stats on transaction sponsorship and account health.
- **Paymaster Management**: Deposit and monitor XLM/USDC used for fee sponsorship.
- **Smart Account Analytics**: Track the growth and activity of users on your platform.
- **Intent Monitoring**: Deep-dive into specific transaction XDRs and execution status.

---

## 🛠 Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Blockchain**: @stellar/stellar-sdk

---

## 🏁 Getting Started

### 1. Clone the repo
```bash
git clone https://github.com/MeavenMay/stellar-axis-console
cd stellar-axis-console
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the console in action.
